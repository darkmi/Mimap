# Mimap（KityMinder Editor）全功能测试方案

> 覆盖范围：页面全部菜单、工具栏、弹窗、导航器、备注、快捷键、数据操作
> 自动化框架：Playwright（E2E）+ Vitest（单元）
> 用例总数：**128 个**（A~J 共 10 个功能区）

---

## 测试执行

```bash
# 运行全部 E2E 测试
npm run test:e2e

# 运行单元测试
npm test

# 运行指定分组
npx playwright test --grep "@group-A"
npx playwright test --grep "@group-B"
```
